# portofolio

Buat sebuah website portofolio pribadi untuk seorang siswa SMA kelas 12 bernama Fahri Az-Zuhri.

Konsep Utama

Website memiliki tema Formula 1-inspired dark racing technology dengan nuansa modern, agresif, premium, dan profesional.

Website jangan terlihat seperti website resmi tim Formula 1 tertentu. Gunakan hanya inspirasi visual dari dunia balap dan motorsport, seperti telemetry, dashboard, racing grid, speed lines, dan teknologi kendaraan.

Color Palette

Gunakan kombinasi warna:

Background utama: hitam pekat #080808

Background sekunder: #111111

Dark red: #3B0808

Primary red: #E10600

Bright red untuk highlight: #FF1E14

White: #F5F5F5

Gray: #8A8A8A

Warna merah digunakan sebagai aksen, jangan memenuhi seluruh halaman.

Visual Style

Gunakan desain:

Dark futuristic

Racing technology

Minimalist

Premium

High-tech

Aggressive but clean

Banyak whitespace

Garis diagonal tipis

Grid background yang sangat subtle

Telemetry-inspired graphics

Numbered sections seperti 01, 02, 03

Border merah tipis pada beberapa elemen

Subtle glow merah

Smooth hover effects

Smooth scrolling

Animasi yang cepat dan elegan

Jangan membuat website terlalu ramai.

Struktur Website

01 — HERO

Tampilkan:

FAHRI AZ-ZUHRI

Subtitle:

GRADE 12 STUDENT • DEVELOPER • AI ENGINEER

Deskripsi singkat:

"SMA student passionate about programming, artificial intelligence, cybersecurity, languages, and technology."

Tambahkan tombol:

VIEW PROJECTS

dan

CONTACT ME

Buat hero section terlihat seperti dashboard teknologi mobil balap modern.

Tambahkan elemen visual seperti:

Racing telemetry lines

Grid

Speed lines

Data indicators

Animated red lines

Namun tetap pertahankan keterbacaan teks.

02 — ABOUT ME

Judul:

ABOUT ME

Tampilkan bahwa Fahri Az-Zuhri adalah siswa SMA kelas 12 yang memiliki ketertarikan pada teknologi, programming, artificial intelligence, cybersecurity, bahasa, dan public speaking.

Buat layout modern dengan nomor besar:

02

di sisi kiri sebagai elemen dekoratif.

03 — SKILLS

Judul:

SKILLS

Tampilkan skill dalam bentuk modern racing dashboard.

Skills:

Programming / Coding

AI Engineering

Pentesting

English

Arabic

Public Speaking

Jangan menggunakan progress bar yang seolah-olah menunjukkan persentase kemampuan. Gunakan card, tag, atau indikator visual saja.

Contoh:

01  PROGRAMMING
    CODE • DEVELOPMENT

02  AI ENGINEERING
    MACHINE LEARNING • AI

03  PENTESTING
    CYBERSECURITY • SECURITY

04  ENGLISH
    LANGUAGE

05  ARABIC
    LANGUAGE

06  PUBLIC SPEAKING
    COMMUNICATION


04 — PROJECTS

Buat section:

SELECTED PROJECTS

Sediakan beberapa project card yang nantinya dapat diisi dengan proyek Fahri.

Setiap card memiliki:

Project number

Project name

Short description

Technology used

View Project button

Gunakan desain seperti kartu data/telemetry dengan border dark red.

Jika belum ada project yang dimasukkan, gunakan placeholder yang mudah diganti.

05 — EXPERIENCE / JOURNEY

Buat timeline perjalanan belajar Fahri.

Gunakan style seperti racing timeline:

START
  │
  ├── Programming
  │
  ├── AI Engineering
  │
  ├── Cybersecurity
  │
  └── Future Goals


Section ini harus mudah diperbarui ketika Fahri memiliki pengalaman atau pencapaian baru.

06 — CONTACT

Judul:

LET'S CONNECT

Tampilkan beberapa opsi kontak/social media yang bisa diisi nanti.

Buat contact section minimalis dengan background hitam dan aksen merah.

Tambahkan CTA:

READY TO BUILD SOMETHING?

Navigation

Navbar harus sederhana:

FAHRI AZ-ZUHRI

HOME
ABOUT
SKILLS
PROJECTS
CONTACT


Navbar dapat berubah menjadi sticky navbar ketika user melakukan scrolling.

Gunakan efek hover merah.

Typography

Gunakan font yang terasa seperti typography motorsport modern.

Gunakan kombinasi:

Font bold/condensed untuk heading

Font modern sans-serif untuk body text

Monospace font untuk elemen telemetry, angka, dan data

Heading harus terlihat kuat dan tegas.

Animations

Tambahkan animasi yang halus:

Fade-in ketika section muncul

Slide-in untuk beberapa elemen

Hover effect pada card

Red glow yang subtle

Moving telemetry lines

Smooth scrolling

Button hover animation

Hindari animasi berlebihan yang membuat website lambat.

Responsive Design

Website harus sepenuhnya responsive untuk:

Desktop

Laptop

Tablet

Smartphone

Pastikan layout tetap rapi pada layar kecil.

Overall Impression

Website harus terasa seperti:

F1 Racing × Technology × AI × Cybersecurity

dengan identitas pribadi Fahri Az-Zuhri.

Hasil akhir harus terlihat seperti portfolio seorang calon developer/AI engineer yang serius, modern, dan memiliki karakter kuat — bukan seperti template portfolio biasa.
